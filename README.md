# 全局均衡器 (Global EQ)

简体中文 | [English](README.en.md)

一款安卓**系统级全局均衡器**。利用 Android `DynamicsProcessing` 音效挂载到全局音频输出（audio session 0），对本机播放的**所有媒体声**（音乐 / 视频 / 游戏）做逐频点增益调节——不依赖耳机固件的任何 EQ 能力，也不需要蓝牙权限。

## 功能特性

- **十段均衡器**（31Hz – 16kHz），每段 ±12dB，0.5dB 步进；竖直推子为 Canvas 自绘，拖动时不会与页面滚动冲突，按下有触感反馈
- **7 个预设**：平坦 / 压低音 / 低音增强 / 人声清晰 / 高音增强 / 夜间小声 / 播客人声。预设曲线按实际频段中心做对数域线性插值，无论设备报告多少频段都能正确套用；手动调推子后自动标记「自定义」
- **前级增益** ±6dB（整体补偿响度），**限幅器常开**防止增益叠加后削波
- **前台服务保活**：常驻通知实时显示「运行中 · 频段数 · 当前预设」，通知内一键「停用」；从最近任务划掉应用音效不丢
- **开机自恢复**：重启手机后自动回到上次的开关状态与曲线
- 所有状态（开关 / 每段增益 / 前级 / 预设名）本地持久化，重开应用原样恢复
- 深色主题、自适应启动图标；APK 约 30KB，**零第三方依赖**

## 工作原理

- 创建 `DynamicsProcessing`（立体声、前置 EQ、限幅器开启），挂到 **audio session 0**（全局输出混合），对本机所有媒体输出通路生效；
- 频段数按 `10 → 6 → 5 → 8 → 12` 顺序尝试创建，取系统支持的第一个；
- `EqService` 前台服务持有音效实例防止被系统回收；`BootReceiver` 在开机完成后自动重建。

## 适用机型 / 系统限制

| 项目 | 要求 / 说明 |
| --- | --- |
| 系统版本 | Android 9.0（API 28）及以上，`DynamicsProcessing` 自 API 28 引入 |
| ROM 音效支持 | 系统需包含 AOSP 的 `dynamics_processing` 音效实现（绝大多数机型都有）。个别深度定制 ROM 限制第三方应用挂全局音效，应用启动时会自动探测并明确报错提示 |
| 生效范围 | 仅**本机**播放的媒体声：蓝牙耳机 / 音箱、有线、外放等所有输出通路都生效 |
| 不生效场景 | 通话语音；耳机连接电脑等**其他设备**播放时；少数走硬件 offload 直通的播放路径可能绕过均衡器 |
| 进程存活 | 系统深度清理或 force-stop 会令音效失效。建议在系统设置中允许本应用「自启动」并关闭电池优化；前台服务已显著提升存活率 |
| 通知权限 | Android 13+ 需授予通知权限，否则常驻通知不可见（部分国产 ROM 对 adb 安装的应用默认静音通知；**不影响音效本身**） |
| 音效叠加 | 与其他挂 session 0 的均衡器类应用同时开启会叠加作用，注意不要重复调音 |

## 构建与安装

无需 gradle，直接用 SDK build-tools 工具链（aapt2 → javac → d8 → zipalign → apksigner）：

```bash
bash build_app.sh
# 产物: build/GlobalEQ.apk
adb install -r build/GlobalEQ.apk
```

依赖：Android SDK（platform android-34、build-tools 34.0.0 与 37.0.0 的 d8）、JDK 21。路径在脚本头部按需修改。

首次使用：打开应用 → 授予通知权限 → 打开「启用全局均衡器」→ 选择预设（压低音）或直接拖推子。
